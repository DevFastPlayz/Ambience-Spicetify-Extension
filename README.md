
# Atmosphere

Atmosphere is a Spicetify extension that adds ambient
background sounds while listening to Spotify.

## Features

- Built-in ambient sound recordings
- Individual volume controls
- Enable/disable each sound
- Saves your volume preferences
- Continues playing when Spotify music is paused

## How to Use

1. Install Atmosphere from Spicetify Marketplace.
2. Open Spotify.
3. Click the Atmosphere button in the top bar.
4. Enable your preferred sounds.
5. Adjust each sound's volume.

## Requirements

- Spotify Desktop
- Spicetify
